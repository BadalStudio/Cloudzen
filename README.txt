# Codez — Code Studio (manual replacement files)

## Install / replace
1. Download and extract `Codez_Project_Files.zip`.
2. Make a backup of your current GitHub repository first.
3. Replace these files in the repository root: `index.html`, `style.css`, `app.js`, and `highlight.js`.
4. Commit the changes to GitHub. Wait for GitHub Pages to redeploy, then refresh your site.

## Included
- Dark midnight / violet / cyan premium theme and light theme
- Multi-file explorer with nested paths, create folder, create file, rename/move and delete
- Multiple editor tabs, syntax colour palettes, adjustable font size
- Find, next/previous, replace and replace all
- Ctrl/Cmd+S save shortcut, Tab indentation and extra coding keys
- ZIP import/export (JSZip CDN needs an internet connection)
- Split preview and full preview; preview position setting
- Desktop mode and resizable explorer/preview panels
- Local username/profile only

## Important limitations
- Username is stored locally in this browser/device. It is NOT Gmail login, cloud sync, or a secure account system.
- Project data uses browser localStorage, so export ZIP backups regularly.
- The preview iframe is sandboxed, but this is still a beginner editor; don't run untrusted code.
- ZIP import/export loads JSZip from a CDN, so ZIP actions need internet access.
- This package was generated as a starter update and has not been tested on every Android/browser/device. Test before relying on it for important work.
